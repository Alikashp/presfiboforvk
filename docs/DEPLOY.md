# Деплой на Railway

Итог: адрес вида `https://<имя>.up.railway.app`, по нему открывается
веб-интерфейс, вход по паролю. Без трафика сервис засыпает и не тратит
деньги; первый заход после сна его будит.

Всё, что можно держать в коде, лежит в коде:

| что | где |
|---|---|
| сборка из `Dockerfile` | `railway.json` → `build` |
| засыпание без трафика | `railway.json` → `deploy.sleepApplication: true` |
| проверка здоровья | `railway.json` → `deploy.healthcheckPath: /_stcore/health` |
| порт из `$PORT` хостинга | `Dockerfile` → `CMD` |
| пароль на интерфейс | переменная `DECKWRIGHT_PASSWORD` |

Шаг CI `docker build` собирает тот же образ, запускает его с `PORT=8080` и
ждёт ответа `/_stcore/health`. Зелёный CI — значит, образ поднимается.

## Пошагово

1. **Смержить PR в `main`.** Railway собирает ту ветку, которую ему укажут;
   берите `main`.
2. **railway.com → New Project → Deploy from GitHub repo.** Если Railway
   попросит доступ к GitHub, дайте его на репозиторий
   `Alikashp/presfiboforvk` (репозиторий приватный, без этого списка не
   будет). Выберите репозиторий.
3. Railway найдёт `railway.json` и начнёт сборку по `Dockerfile`. Первая
   сборка — около 5–8 минут: LibreOffice и шрифты. Дождитесь, пока она
   упадёт или пройдёт, — переменные можно задать и после.
4. **Вкладка Variables → New Variable**, по одной:

   | переменная | значение |
   |---|---|
   | `LLM_BASE_URL` | `https://api.siliconflow.com/v1` |
   | `LLM_API_KEY` | ключ SiliconFlow (тот же, что в секрете `LLM_API_KEY` репозитория) |
   | `LLM_MODEL` | `Qwen/Qwen3.6-27B` |
   | `VLM_BASE_URL` | `https://api.siliconflow.com/v1` |
   | `VLM_API_KEY` | тот же ключ |
   | `VLM_MODEL` | `Qwen/Qwen3.6-27B` — модель, на которой замерен аудит (#10, #12) |
   | `DECKWRIGHT_PASSWORD` | пароль на вход, любой, не короче 12 символов |

   `PORT` **не задавайте** — Railway ставит его сам. После сохранения
   переменных Railway перезапустит сервис.
5. **Settings → Networking → Generate Domain.** Railway выдаст адрес
   `*.up.railway.app`. Если спросит порт — оставьте тот, что предложит
   (он же `$PORT`).
6. **Settings → проверьте, что Serverless включён.** Он включается из
   `railway.json`; если переключатель выключен, включите руками — см.
   «Если что-то не так».
7. **Откройте адрес.** Страница спросит пароль. Дальше: загрузить шаблон
   из `data/templates/`, отметить «демонстрационный контент-пакет», снять
   «Записанные ответы модели», «Собрать».

## Что важно знать

**Засыпание.** Railway усыпляет сервис, когда тот 5–10 минут не отправляет
исходящего трафика. Открытая вкладка с интерфейсом держит соединение, и
сервис не уснёт, пока её не закрыть. Идущий прогон тоже держит: он ходит
в модель. Первый заход после сна — холодный старт, около 10–20 секунд, пока
поднимается Streamlit.

**Результаты не хранятся.** Файлы прогона лежат в файловой системе
контейнера и пропадают при передеплое или перезапуске после сна. Нужные
`.pptx`/`.pdf` скачивайте сразу из интерфейса.

**Пароль — это единственная защита ключа.** Без `DECKWRIGHT_PASSWORD`
интерфейс открыт всем, кто знает адрес, и каждый прогон тратит ключ.
Интерфейс в этом случае показывает предупреждение.

**Память.** LibreOffice при конвертации в PDF занимает сотни мегабайт. Если
в логах деплоя процесс убит по памяти (`OOMKilled`), поднимите лимит в
Settings → Resources.

## Если что-то не так

* **Сборка упала на `deckwright doctor`.** Не нашёлся системный пакет —
  тот же шаг падает в CI; смотрите лог CI на этом коммите.
* **Deploy висит на healthcheck.** Смотрите Deploy Logs: Streamlit обязан
  написать `You can now view your Streamlit app`. Если его нет — ошибка
  импорта, её видно выше в логе.
* **Serverless выключен, хотя в `railway.json` включён.** Railway объявил
  config-as-code (`railway.json`) устаревшим в пользу
  `.railway/railway.ts`; существующие файлы, по их документации, работают
  до 2026-12-01. Если панель настройку не подхватила — включите Serverless
  в Settings руками, результат тот же.
* **«Модель не настроена».** Не заданы `LLM_*`; после добавления
  переменных сервис должен был перезапуститься сам — если нет, Redeploy.
