# deckwright

Читает произвольный `.pptx` как набор правил дизайн-системы и собирает по нему
новые слайды: три варианта вёрстки на одном контенте, нативные объекты в
`.pptx`, встроенный аудит качества, экспорт в `.pdf` и `.html`.

Кейс VK Tech «Цифровой дизайнер презентаций», ЛЦТ 2026.

## Статус

В разработке. Пройдены фазы 0–9 и цикл исправления фазы 10. См.
`progress/handoff.md`.

## Запуск

```bash
deckwright doctor                       # проверить системные зависимости
deckwright run \
  --config configs/config.yaml \
  --template путь/к/шаблону.pptx \
  --content контент-пакет.json \
  --variant balanced                    # без флага — все три варианта
```

Без ключа модели прогон идёт по записанным ответам: добавьте
`--recorded tests/fixtures/recorded`.

**Что делать с находками аудита** — флаг `--fix` (по умолчанию режим из
`config.yaml`, там `review`):

| режим | что делает |
|---|---|
| `review` | показывает отчёт с ключами находок и **не трогает колоду**: выбирает человек |
| `auto` | применяет находки с исправлением `automatic` и пересобирает колоду |
| `off` | не запускает цикл исправления |

Находки, требующие решения человека (`assisted`) и ответы модели (контекстные),
не применяются ни в одном режиме — только явным выбором в интерфейсе. Подробнее
в [`docs/AUDIT.md`](docs/AUDIT.md), раздел «Цикл исправления».

## Сетап

### Через Docker (рекомендуется)

Образ несёт LibreOffice Impress, poppler и шрифты — без них конвертация и
измерение текста не работают.

```bash
cp .env.example .env      # заполнить ключи
docker compose up --build
```

Интерфейс — http://localhost:8501

### Локально

Нужны системные пакеты: `libreoffice-impress`, `poppler-utils`, `libeot-utils`.

```bash
cp .env.example .env
pip install -e ".[dev]"
streamlit run app/ui.py
```

## Переменные окружения

Все секреты — только в `.env`, шаблон в `.env.example`. В `configs/config.yaml`
лежат ссылки `${VAR}`, значений там нет.

| переменная | назначение |
|---|---|
| `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL` | OpenAI-совместимый endpoint модели с открытыми весами |
| `VLM_BASE_URL`, `VLM_API_KEY`, `VLM_MODEL` | модель со зрением для контекстного аудита; может совпадать с LLM |
| `T2I_BASE_URL`, `T2I_API_KEY`, `T2I_MODEL` | text-to-image; по умолчанию выключено |

## Ограничения

- Вход — только `.pptx` и `.potx`. PDF, Keynote и Google Slides напрямую не
  принимаются.
- Только десктопные браузеры: Chrome, Firefox, Safari, Яндекс Браузер.
- Сервис не является редактором слайдов: он показывает найденные проблемы и
  чинит выбранные, но не даёт двигать блоки руками.
- Если встроенный в шаблон шрифт распаковать не удалось, подставляется
  метрически близкий; факт подстановки пишется в манифест прогона и в аудит.
- Если в шаблоне нет ни одного примера графика, форма графика будет наша, а
  цвета и типографика — шаблона. Это отражается в отчёте аудита.
- Генерация требует внешнего endpoint'а модели: GPU локально не нужен, но без
  доступа к модели работает только разбор шаблона.
